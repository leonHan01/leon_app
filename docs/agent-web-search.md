# Agent 联网搜索

2026-11-21：本地服务端实现，尚未部署正式服务。Mac、Android、iOS 沿用现有 Markdown 链接，无客户端协议变更。

## 使用

1. 部署同级 `leon_lite_workflow` 服务端本次更新。
2. 打开「Agent 工作台」，编辑一个 OpenAI Agent，勾选「允许此 Agent 联网搜索」并保存。对话模型需支持 Responses API 的 `web_search`，复用该 Agent 的模型与凭据。
3. 私聊发送「联网查一下最新版本，附官方来源」；群聊先 @ 对应 Agent。回复在相关事实旁显示「来源1」等可点击链接，末尾列出去重后的来源标题。

新建和已有 Agent 默认不启用搜索，旧管理请求省略 `webSearchEnabled` 时保留原值。搜索与绘图开关独立，可以同时开启。DeepSeek 不提供此开关，服务端拒绝为其启用。模型实际权限或工具支持不足时显示错误，不静默回退为未经查证的回答。

## 行为与限制

- 交互回复通过固定官方 `/v1/responses` 端点，启用 `web_search` 并允许实时网络访问；服务端直连与 Mac 执行器两种路径均支持。模型根据问题决定是否搜索，最新、查证及明确联网请求会被指示实际查询。普通写作、翻译和闲聊可以直接回答。
- 请求携带北京时间日期，指示模型优先官方与原始来源、区分事件与发布日期。网页内容按资料处理，不接受其要求执行额外操作的指令；查询只使用问题所需公开关键词。
- 摘要压缩、自动标题、归档总结等后台调用继续走纯文字路径，不开放搜索和绘图工具。
- 每次交互最多 6 次工具调用，可用于搜索、打开页面或查找；同时开启绘图时仍只允许生成一张图片。延续现有 240 秒执行器任务上限、230 秒直连请求上限及 8,000 字符回复限制，不提供长时间后台研究。
- 根据 OpenAI `url_citation` 注解生成 Markdown 行内链接及来源列表；保留原有回答文字、去重来源、清理内部引用标记，并处理中文、emoji 和无效偏移。仅接收不含用户凭据的 HTTP / HTTPS URL，转义来源标题。每条回复最多 24 个来源，超出范围或总回复过长时失败，不截断来源。
- 搜索失败、返回未完成状态或已搜索但没有可用来源链接时，保存失败状态供手动重试，不把该结果保存为成功的查证回复。不自动重新调用付费模型。
- 来源作为正文保存，历史同步、复制、引用、收藏、备份及导出沿用原有文字处理。链接的保存不代表后台持续检查网页是否更新。
- 复用既有加密凭据与认证；配置仅由管理页面会话修改。文本 Token 正常记录，当前 Token 费用估算不包含独立搜索工具费，不将未统计费用当作零。
