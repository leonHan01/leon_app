## 引用回复与收藏（0.14.0）

长按文字、富文本或图片消息，选择「引用 / 收藏」。引用在输入框上方预览，可取消；发送后显示原文卡片，点击查看源消息上下文。引用与文字 / 图片草稿按会话隔离，待发队列保存引用标识和本地预览；服务器校验当前会话权限并保存原文快照。引用不会改变 Agent 触发规则或原有回复关联。

「设置 → 收藏」和聊天更多菜单进入账号私有收藏。支持搜索、分页、详情、原消息定位和取消收藏。收藏图片从独立、需账号认证的端点读取，原会话清理后仍保留收藏内容。图片长按菜单继续提供已有的保存功能，并加入引用 / 收藏。

与 Mac 0.12.0、Android 0.13.0 同步实现。服务端已完成本地更新、测试和打包，**尚未部署**；引用会在发送前检查服务端能力，旧版会提示升级并保留待发消息。当前 0.14.0 只生成本地签名包，最近安装并启动的手机版本仍为 0.13.4（build 11）。

## 打开与构建

在仓库根目录准备离线正文资源：

```bash
npm ci --prefix shared/markdown
node ios/Tools/prepare-assets.mjs
python3 ios/Tools/generate-project.py
```

然后用完整 Xcode 打开 `ios/Leon.xcodeproj`，选择 `Leon` scheme。真机运行需要在 Signing & Capabilities 中设置自己的开发团队和可用 Bundle ID。首次运行前确保服务端已支持下述 iOS 平台字段。

可用脚本只编译，不启动 App 或模拟器：

```bash
bash scripts/build-ios.sh simulator
bash scripts/build-ios.sh device
```

脚本检查完整 Xcode、运行核心与正文检查、准备资源并构建。输出分别是 `dist/Leon-iOS-simulator-unsigned.zip` / `dist/Leon-iOS-device-unsigned.zip`，包含未签名的 `.app`。设备 ZIP 不是可直接安装的 IPA；签名、归档、TestFlight / App Store 分发须在 Xcode 中完成。

当前安装包为 `dist/Leon-iOS-personal-0.16.2.ipa`（约 3 MB）。仅保留各平台最新版本化安装包，构建脚本直接生成的临时产物在整理后去重；历史安装备份目录保留。新包通过 `codesign --verify --deep --strict` 及 ZIP 内容完整性检查。描述文件已确认包含当前 iPhone，个人签名有效期至 **2026-11-27 21:42（北京时间）**。此包仅供已登记设备使用，不能在手机上点开当作 APK 安装；有效期届满需要重新签名安装。个人签名构建使用 Xcode 中选定的 Personal Team，普通构建脚本仍输出未签名版本。

`Resources/Markdown` 是被忽略的生成目录；正文补丁只作用于该 iOS 副本，不修改现有两端使用的资源。直接从干净检出打开工程前须执行资源准备步骤。

## 服务端兼容

客户端发送真实的 `platform: ios`。`ServerCompatibility/ios-platform.patch` 保留原迁移阶段必要的兼容改动：允许 iOS 发送消息、设备心跳和备份消息，并在在线设备列表显示 iOS。`IosClientCompatibilityTest.java` 是对应的服务端回归用例。

`ServerCompatibility/group-agents.patch` 补齐向已有群聊添加 Agent 的端点、聊天会话认证白名单、群主权限、原子追加与限制校验，并包含账号集成回归用例；不需要数据库迁移。`ChatAccountIntegrationTest` 的 5 项检查及 iOS 兼容的 2 项检查通过，服务端本地 Maven 打包通过。默认设备群聊和私聊拒绝邀请，成员添加需由自建群聊的群主操作。

同级服务端项目中的这些兼容改动继续保留，`IosClientCompatibilityTest` 的 2 项检查通过（JDK 21、H2 内存数据库）。**本次工作没有部署服务端，未核验公网部署版本**。若目标服务器仍只允许 `macos` / `android`，需要先合入并部署平台兼容改动；不要把 iOS 伪装为 Android。群聊、UserName、上下文、独立对话及 ZIP 备份还需要现有对应版本接口和 32 MB 反向代理配置。
